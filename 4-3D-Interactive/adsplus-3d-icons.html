3D service icons

Built to move brands forward+

Five animated 3D icons for the website, one for each core service in the company profile, rendered in the brand's red glass. Drag any icon to turn it. Each animation loops every 4 seconds and can be saved as a transparent video or a PNG.

For the developer: load three.js r128 and the script in this file, then call AdsIcons.mount(element, "consultancy") on any empty square element. The names are consultancy, performance, campaign, media and social. The canvas background is transparent, so the icons sit on any page color.
